# FlexiCup Hardware Design

This directory contains the hardware design files for the FlexiCup system.

## Directory Structure

- **CAD/**: 3D CAD models and mechanical design files
- **PCB/**: PCB design files, schematics, and Gerber files

## CAD Files

The CAD directory contains STEP files for:
- FlexiCup_Vacuum.STEP: Vacuum suction mode configuration
- FlexiCup_Bernoulli.STEP: Bernoulli suction mode configuration
- Various modular bottom configurations (I-IV)

## PCB Design

The PCB directory includes:
- Schematic diagrams
- PCB layout files
- Bill of Materials (BOM)
- Gerber files for manufacturing

## Manufacturing

All design files are ready for manufacturing and include detailed specifications for component sourcing and assembly.
